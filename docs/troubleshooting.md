# 常见问题

## 访问与登录

**打开页面返回 403，提示 Host 不被允许。**
请求的 `Host` 头不在 `DLS_ALLOWED_HOSTS` 里。把反代域名、Tailscale/Cloudflare 主机名、局域网 IP 明确加进去，重启服务。

**登录成功后立刻回到登录页。**
HTTPS 反代没有把协议告诉应用。设置 `DLS_TRUST_PROXY=true`，确保代理发送 `X-Forwarded-Proto: https`；同时确认浏览器没有拦截 Secure Cookie。也可以临时用 `DLS_SECURE_COOKIES=never` 排查，但不建议长期使用。

**本机录音没有声音，或浏览器没有“分享音频”选项。**
选择“系统声音”时需要在浏览器弹窗里勾选“分享音频”。macOS 通常只能分享浏览器提供的标签页/应用音频；要采集整机系统声音需要安装回环设备。也可以改用麦克风。

**忘记管理员密码。**
在项目目录执行：

```sh
uv run --env-file .env douyin-live-sense reset-password
```

新密码只打印一次，同时会让已登录的浏览器失效。日常修改密码用网页菜单“修改登录密码”。

## 采集

**一直显示“等待开播”。**
守卫每 30 秒检查一次，房间未开播时会一直等待。确认房间号或链接正确，并确认直播间当前确实在播。

**提示需要处理，或停止重试。**
抖音要求登录或触发风控。在 `.env` 的 `DOUYIN_COOKIE` 填入自己的登录 Cookie 后重启服务。默认会先尝试匿名访问，能否匿名取决于抖音当前响应。

**采集过程中出现缺口。**
电脑休眠、网络中断或服务停止都会留下真实缺口，缺口记录在数据库并通过场次事件接口读取，不会用静音填补。恢复网络后守卫会自动重连，同一场次继续。

**磁盘不足后采集停止。**
剩余空间不足 1 GB 时会保存尾段并停止。清理空间后再从网页手动开启；历史音频不会自动删除。

**提示另一个任务正在运行。**
直播间守卫与本机录音互斥，同一时间只能运行一个；同一数据目录也只允许一个服务实例。先停止当前任务。

## 分析与模型

**按钮不可用，提示先选择“纯本地模型识别”。**
默认是仅录音。到“网站配置 → 识别方式配置”切换到纯本地模型识别；Linux ARM64 不支持分析，只能录音。

**模型下载返回 401/403。**
确认 Token 是只读 Token、已在 [Community-1 页面](https://huggingface.co/pyannote/speaker-diarization-community-1)接受条款。Token 只保存在 `data/models/hf_token`，不要写进 URL、日志或公开配置。

**提示分析依赖未安装（`needs_dependencies`）。**
在支持分析的平台执行 `./scripts/setup.sh` 或 `uv sync --locked --extra analysis`，然后重启服务。

**分析一直排队或很慢。**
模型在独立子进程中串行处理，首次加载、长切片和补分析积压都会增加等待。队列页会如实显示当前任务、等待数量和每个切片的状态。

**指定 `DLS_DIARIZATION_DEVICE=mps` 后报错。**
该设备不可用。改回 `auto`，让程序选择可用的 CUDA、Apple MPS 或 CPU。

**人物编号前后不一致。**
人物只在同一场次、同一分析版本内复用。不同场次、单片复核版本、更换模型后的新版本都是独立的。样本过短或匹配不明确时显示“人物待确认”。

## 音频与档案

**整场 ZIP 下载返回 404。**
该场次还没有任何已保存完成的切片。等待采集写出切片后再试；正在写入的 `.part` 文件不会进入 ZIP。

**删除合集返回 409。**
该合集正在采集或有未完成的分析任务。先停止采集、等待分析结束再删除。删除是硬删除，数据库记录、音频文件和分析结果都会移除，无法恢复。

**回听某条发言时听不到开头。**
跨切片的发言会从多个 WAV 重建；如果其中某个源切片被删除，重建会失败。回听单段音频用切片上的播放按钮。

**想迁移到另一台机器。**
停止服务后复制整个 `data/`，在新机器上用同样的 `DLS_DATA_DIR` 启动；登录密码、场次、音频和模型都会一起带过去。
